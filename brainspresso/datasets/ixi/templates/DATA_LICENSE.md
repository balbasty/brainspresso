# Licence of the bundled IXI files

`IXI.xls` (demographics), `bvals.txt` and `bvecs.txt` (diffusion
gradients) are copies of files from the original IXI release, which is
no longer online (https://brain-development.org/ixi-dataset/). They are
bundled so that `bx ixi roast` can still build `participants.tsv` and the
DWI b-values/vectors when the images are harvested from NITRC-IR, which
does not host these files.

https://creativecommons.org/licenses/by-sa/3.0/.
The rest of brainspresso is under the MIT licence (see `LICENSE`).
