# FCON1000

The *1000 Functional Connectomes Project* (FCON1000, or F1000) was the first
large release of the International Neuroimaging Data-sharing Initiative. In
2009–2010 it pooled resting-state fMRI and anatomical scans that 33 sites had
already collected, from about 1300 mostly healthy participants, to show that
resting-state data could be aggregated across centres for discovery science.

## Contents

* `anat/*_T1w.nii.gz` and `func/*_task-rest_bold.nii.gz`. Sites that acquired
  several resting runs (ICBM, NewHaven_a, NewHaven_b) have `run-<n>`. Only
  NYU_TRT has sessions.
* `participants.tsv`, merged from the site tables, with a `site` column. Some
  sites did not share demographics.
* With `--folders derivatives`: skull-stripped T1w images
  (`derivatives/fcon1000/`, `desc-brain_T1w`). For NewHaven_a and NewHaven_b,
  these are the only anatomical images available.
* Site notes and extra tables are kept in `sourcedata/<site>/`.

## Curation

The bucket copy is organised by site and is not BIDS. brainspresso merges it
into one dataset:

* Subject labels are only unique within a site, so each is prefixed with its
  site: `AnnArbor_a/sub-04111` becomes `sub-AnnArborA04111`. The original label
  is kept in `participants.tsv`. `--layout sites` keeps the original labels in
  one dataset per site (see [multi-site projects](index.md#multi-site-projects)).
* Typos in the bucket's file names are corrected (`tast-rest`, `_boldt`,
  `T1wnii.gz`), and empty marker files such as `no_T1w` are skipped.
* Functional sidecars are generated, with the repetition time read from the
  NIfTI headers.
* In the participant tables, `handed` becomes `handedness`, sex is coded `M`
  or `F`, and `9999` becomes `n/a`.

## Examples

```shell
bx fcon1000 info
bx fcon1000 harvest /data --sites ICBM NYU_TRT --datatypes func --dry-run
bx fcon1000 harvest /data --where "age>=60" --folders derivatives
bx fcon1000 harvest /data --layout sites --sites ICBM --subs 00448
```
